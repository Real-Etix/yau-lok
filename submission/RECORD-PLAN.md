# 有落 — 3-hour demo video, no camera

You are not filming anything. The video is a **screen recording of the app**,
a narration track, and burned-in subtitles. Assembly is one `ffmpeg` command,
so there is no editor to learn.

**Format:** 1080×1920 vertical. The app is a phone app — vertical fills the
frame instead of stranding it in the middle of a 16:9 letterbox. The rules
allow either.

**Total runtime: 4:10.** Inside the 3–5 min window with room either side.

## Before you record (15 min)

1. **Fix the Simplified route names.** Open the app in 繁體中文, clear the
   saved route, re-save it. Otherwise the home screen shows 石排湾邨 in a
   Traditional UI and a HK judge will notice immediately.
2. **Seed a last order** so the 茶餐廳 tile shows a real chit instead of
   未落過單: run through 茶餐廳 once and press 埋單.
3. **Prepare a menu photo** for the 影餐牌 clip — a real 餐牌 photo on your
   phone, or any printed Chinese menu. It does not need to be a good one.
4. **Browser to a 9:16-ish window**, roughly 405×720. Hide bookmarks, close
   other tabs, put the machine in Do Not Disturb.
5. **Turn the volume up** — clip 02 and 05 play real Cantonese TTS and that
   audio needs to land in the recording.

Record with **⌘⇧5 → Record Selected Portion**. One clip per file, into
`submission/clips/`, named exactly as below. Don't trim anything: the
assembly script cuts each clip to the exact length itself.

## The 8 clips

Record a couple of seconds longer than the target — the script trims from the
start of each file.

| File | Length | What happens on screen |
|---|---|---|
| `01-home.mov` | 0:12 | Load the home screen. Don't touch it. Let the four live numbers sit there. |
| `02-minibus.mov` | 0:45 | Tap 綠色小巴 → pick the route → 上車 → let the map run → the stop alert fires → tap **幫我嗌「有落」** and let the Cantonese play out loud. |
| `03-taxi.mov` | 0:35 | Back → 的士 → type a destination → show the fare estimate and the meter → play the "tell the driver" line. |
| `04-clinic.mov` | 0:35 | Back → 睇醫生 → the A&E wait list → tap through to describe a symptom → show the triage/fee card. |
| `05-cct.mov` | 0:45 | Back → 茶餐廳 → 開始落單 → tap 檸茶, then **走冰** and **走甜** → 寫張單 → hold on the chit reading `0T 走冰 走甜` → tap 讀廣東話俾伙記聽. |
| `06-scan.mov` | 0:40 | 影張餐牌落單 → take/choose the photo → the recognised lines appear → **tap 改 on a line it got wrong and fix it** → build the chit. |
| `07-language.mov` | 0:25 | Home → language pill → **Bahasa Indonesia** → let the whole UI flip → switch again to **اردو** so the layout mirrors right-to-left. |
| `08-close` | 0:13 | **Nothing to record.** `assemble.sh` builds this from `assets/close-card.png` — the 有落 mark, the QR, and the URL, composed at full 1080×1920 so it cuts sharp against the recordings. Rebuild it with `bash submission/make-close-card.sh` if the URL changes. |

**Clip 05 and 06 are the two that win.** 05 is the only moment where the app
writes something a stranger has to act on, and 06 is where you show the OCR
being wrong and being corrected — that reads as judgement, not weakness.
Don't cut either short to save time.

If you run out of clock, drop **04** first, then **03**. Never 02, 05, or 07.

## Narration

Cantonese, generated by **HKGAI's own TTS** — the same voice the product
speaks with. Say so in the subtitles; on the HKGAI track that is a free
credibility point and it costs you no recording time.

If TTS is not cooperating, record the lines on your phone's voice memo app in
one take and drop the file in as `submission/narration.m4a`. That is still not
filming.

Lines are in `NARRATION.md`, timed to the clip lengths above.

---

## Assemble

```bash
bash submission/assemble.sh
```

It pads every clip to exactly 1080×1920, trims each to its target length,
concatenates them in order, lays the narration under, burns in the subtitles,
and exports H.264 under 300 MB. Output: `submission/yau-lok-demo.mp4`.

Check before uploading:

```bash
ffprobe -v error -show_entries format=duration,size -show_entries stream=width,height,codec_name submission/yau-lok-demo.mp4
```

Wanted: `h264`, `1080×1920`, duration between 180 and 300, size under
300000000.
